# Contributing to Nesic

Dự án Nesic do LMD độc quyền phát triển và duy trì (The Nesic project is exclusively developed and maintained by LMD).

## Guidelines

1. **Issues**: If you encounter bugs, have suggestions, or need assistance, please open an issue on GitHub with complete details.
2. **Branching**: If you submit pull requests, branch from `dev` (`dev` is the active development branch; `main` tracks releases).
3. **Coding Standards**: Follow Kotlin and Compose Multiplatform official conventions, Compose single-source-of-truth patterns, and Clean Architecture layer rules.
4. **Pull Requests**: Provide clear descriptions and test your changes thoroughly on Android and/or Desktop.

## AI Policy

AI-assisted contributions are welcome when properly reviewed:
- A human must have written or personally reviewed and tested every line of the PR and be able to answer questions or review comments about it.
- Unattended automated bot submissions without human review will be closed.
